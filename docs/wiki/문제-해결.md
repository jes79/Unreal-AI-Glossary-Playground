# 문제 해결

| 증상 | 원인과 해결 |
| --- | --- |
| "모듈을 다시 빌드할 수 없습니다" | Visual Studio 의 C++ 게임 개발 워크로드와 Windows 11 SDK(10.0.22621) 확인. 또는 `tools/build.sh` 로 빌드해 에러 확인 |
| 레벨·에셋이 수십 바이트짜리 파일 | Git LFS 없이 받은 경우. `git lfs install` 후 `git lfs pull` |
| 레벨이 비었거나 머티리얼이 회색 체크무늬 | **Tools › Glossary › Build All Levels** 로 다시 생성 |
| 콘텐츠 브라우저에서 레벨을 열었는데 캐릭터가 없음 | 정상입니다. 캐릭터·장면 대부분은 **Play** 할 때 데모 액터의 BeginPlay 에서 만들어집니다 |
| 정보 패널이 화면을 가림 | `F1` 로 접기 |
| UI 레벨에서 클릭이 안 됨 | `F3` 으로 마우스 커서 보이기 |
| Play 중 에디터를 못 만짐 | `Shift+F1` 로 마우스를 빼기 |
| 커맨드렛 빌드가 "could not find class" | 해당 분야 모듈이 컴파일되지 않음. `tools/build.sh` 다시 실행 |
| 링크 에러 LNK1104 (DLL 잠김) | 에디터나 다른 언리얼 프로세스가 DLL 을 잡고 있음. 에디터를 닫거나 `tools/locked.sh` 로 한 번에 하나씩 실행 |
| `BT_Enemy` 그래프가 에디터에서 비어 보임 | 코드로 만든 BT 라 에디터 그래프 노드가 없음(실행은 정상). 에디터에서 저장하지 마세요 |
