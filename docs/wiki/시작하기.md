# 시작하기

## 1. 준비물

- **Unreal Engine 5.8** (Epic Games Launcher → 언리얼 엔진 → 라이브러리에서 설치)
- **Visual Studio 2026 또는 2022** + "C++를 사용한 게임 개발" 워크로드 + **Windows 11 SDK (10.0.22621)**
- Git LFS (`.uasset`/`.umap` 이 LFS 로 저장되어 있습니다)

## 2. 받기

```bash
git lfs install
git clone https://github.com/jes79/Unreal-AI-Glossary-Playground.git
```

ZIP 다운로드는 LFS 파일이 빠지므로 쓰지 마세요.

## 3. 빌드와 열기

C++ 프로젝트라 처음 한 번은 빌드가 필요합니다.

- 방법 A: `GlossaryPlayground/GlossaryPlayground.uproject` 를 더블클릭 → "모듈을 다시 빌드할까요?" → **예** (몇 분 걸림)
- 방법 B: 명령줄에서 `tools/build.sh` 실행 후 `.uproject` 열기

Epic Games Launcher 의 **라이브러리 → 내 프로젝트** 에 한 번 열린 뒤부터 나타납니다. 처음엔 "찾아보기"로 `.uproject` 를 고르세요.

저장소에 레벨과 에셋이 들어 있으므로 바로 실행됩니다. 코드를 고쳤거나 레벨이 이상하면 에디터 메뉴 **Tools › Glossary › Build All Levels** (또는 에디터를 닫고 `tools/glossary-build.sh`) 로 다시 만듭니다.

## 4. 둘러보기

### 허브에서 고르기

1. 에디터가 열리면 시작 맵이 `L_0000_Hub` 입니다. 툴바 **Play** (Alt+P)
2. 왼쪽에서 분야, 오른쪽에서 용어를 누르면 그 레벨로 이동
3. `F2` 로 허브에 돌아오기

### 레벨 하나를 바로 열기

- **Ctrl+P** (Open Asset) → `L_0105` 처럼 번호를 치면 바로 찾아 열립니다 → Play
- 또는 콘텐츠 브라우저 `Content/Levels/{NN_분야}/` 에서 `L_{id}_{Name}` 더블클릭 → Play

### 실행 중 조작

| 키 | 기능 |
| --- | --- |
| `F1` | 왼쪽 위 정보 패널 접기/펴기 |
| `F2` | 허브로 돌아가기 |
| `F3` | 마우스 커서 보이기/숨기기 (UI 레벨 클릭용) |
| `Shift+F1` | 에디터 Play 중 마우스를 에디터로 빼기 |
| `Esc` | Play 종료 |
| 1~5, C 등 | 레벨마다 다른 비교 토글 — 정보 패널 '조작' 줄 참고 |

정보 패널에는 **용어 · 쉽게 말하면 · 요청 예문 · 조작 · 실시간 상태** 가 표시됩니다.
대부분의 레벨에 켜기/끄기 비교가 있으니 번갈아 눌러 차이를 느껴 보세요.

## 5. 코드 읽는 법

| 보고 싶은 것 | 위치 |
| --- | --- |
| 기능 로직·장면 구성 | `Source/Glossary{분야}/Public·Private/Demo{id}_{Name}.h/.cpp` |
| 레벨에 저장되는 것(볼륨·정적 라이트) | 데모 클래스의 `BuildLevel()` |
| 생성 에셋(머티리얼·Niagara·BT…) 만드는 코드 | 분야 모듈 `Private/Glossary{분야}Module.cpp`, `*Assets.cpp` |
| 공용 헬퍼 | `Source/GlossaryCore` (`GlossaryKit`, `GlossaryAssetKit`, `AGlossaryDemoBase`) |
| 용어 전체 목록 | `Source/GlossaryCore/Private/GlossaryCatalogData.inl` |
| 분야별 구현 노트 | `docs/dev-notes/NN-*.md` |
