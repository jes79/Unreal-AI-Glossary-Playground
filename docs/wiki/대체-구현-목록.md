# 대체 구현 목록

에디터에서만 만들 수 있는 에셋(Widget Blueprint, 조준 포즈 애니메이션 등)이나 오래 걸리는 굽기 작업이 필요한 용어는
**같은 개념을 C++로 직접 구현**하고, 실제 도구로 하는 방법을 레벨의 정보 패널에 설명합니다.

| id | 용어 | 이 프로젝트의 구현 | 실제로 쓰는 도구 |
| --- | --- | --- | --- |
| 0308 | Aim Offset | 척추 본 회전을 여러 본에 나눠 조준 | Aim Offset 에셋 + 조준 포즈 애니메이션 |
| 0310 | Control Rig (Look At) | Aim + 60° 제한을 C++ AnimInstance 에서 계산 | Control Rig 그래프의 Aim 노드 |
| 0311 | IK Retargeter | 다리 비율이 다른 체형 + 골반 높이 보정 리타깃 | IK Rig + IK Retargeter 에셋 |
| 0312 | Motion Matching | 17클립 포즈 DB + 비용 최소 검색 직접 구현 | Pose Search Database + Motion Matching 노드 |
| 0601 | Widget Blueprint | C++ 위젯 트리 + BindWidget 베이스 클래스 | UMG 디자이너에서 만든 WBP |
| 0607 | Widget Animation | UWidgetAnimation + MovieScene 트랙을 실행 중 조립 | UMG 디자이너의 애니메이션 타임라인 |
| 0616 | Common UI | ActivatableWidgetStack 은 실제, 버튼 스타일만 일반 UButton | CommonButtonBase + 스타일 에셋 |
| 0617 | MVVM | 실제 Viewmodel(FieldNotify) + 코드 구독 | WBP 의 View Bindings |
