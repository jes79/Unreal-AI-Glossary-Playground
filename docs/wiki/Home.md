# Unreal AI Glossary Playground

"언리얼 AI 요청 용어집"의 **187개 용어를 각각 동작하는 예제 레벨**로 만든 학습용 UE 5.8 C++ 프로젝트입니다.
용어를 눈으로 보고, 그 용어로 AI에게 정확히 요청하는 법을 익히는 것이 목표입니다.
[Unity 판](https://github.com/jes79/Unity-AI-Glossary-Playground/wiki)과 같은 구성입니다.

- Unreal Engine 5.8 · C++ · Lumen · Nanite · Enhanced Input · Niagara · GAS · StateTree · MetaSounds · PCG
- 예제 레벨 187개 + 허브 레벨 1개
- 구현 방식: 런타임 데모 170 · 설명 + 대체 구현 14 · 에디터 도구 데모 3
- 레벨·머티리얼·Niagara·사운드·Behavior Tree 등 **모든 에셋을 코드로 생성** (손으로 만든 레벨 없음)
