# AI에게 잘 요청하는 법

AI에게는 "멋있게 해줘" 대신 **정확한 기능 이름 + 조건 + 내 환경**을 함께 말하면 한 번에 원하는 결과가 나옵니다.
각 분야 페이지에서 용어를 찾고, 요청 예문을 내 게임에 맞게 고쳐 쓰세요.

## 좋은 요청의 4요소

1. **대상**: 무엇에 적용하나 (플레이어, 적, 위젯, 투사체…)
2. **기능 용어**: 이 위키의 용어 (예: Dissolve, Coyote Time, Behavior Tree, Gameplay Ability)
3. **조건·수치**: 언제, 얼마나 (예: 체력 30% 이하일 때, 0.5초 동안, Max Walk Speed 600)
4. **내 환경**: UE 버전, **블루프린트인지 C++인지**, 입력 방식(Enhanced Input), 켜 둔 플러그인

| | 예시 |
| --- | --- |
| 나쁜 요청 | "적이 죽으면 멋지게 사라지게 해줘" |
| 좋은 요청 | "UE 5.8 C++ 프로젝트야. 적이 죽으면 머티리얼의 Dissolve 파라미터를 Timeline 으로 1초 동안 0→1 로 올려서 아래에서 위로 사라지게 해줘. 경계선은 주황색 Emissive 로 빛나게 하고, 머티리얼 노드 구성과 Dynamic Material Instance 로 값을 바꾸는 C++ 코드를 같이 알려줘." |

## 결과가 마음에 안 들 때 다시 묻는 법

| 상황 | 이렇게 다시 요청하세요 |
| --- | --- |
| 컴파일 에러 | "이 에러가 나: [Output Log 에러 전문]. 어느 줄이 문제고 어떻게 고쳐? 필요한 Build.cs 모듈도 알려줘." |
| 아무 반응이 없음 | "에러는 없는데 동작을 안 해. 확인할 체크리스트(콜리전 프리셋, Auto Possess, Input Mapping Context 추가, BeginPlay 호출)를 알려줘." |
| 블루프린트로 하고 싶음 | "C++ 말고 블루프린트 노드 순서로 설명해줘. 어느 그래프(Event Graph/Anim Graph)에 놓는지도." |
| 코드가 너무 어려움 | "초보자용으로 다시 설명해줘. 줄마다 주석을 달아줘." |
| 기존 코드와 안 맞음 | "내 현재 클래스야: [헤더와 cpp 붙여넣기]. 여기에 이 기능을 추가하는 방식으로 고쳐줘." |
| 느낌이 별로 | "조절 값(속도, 시간, 강도)을 UPROPERTY(EditAnywhere)로 노출해서 디테일 패널에서 튜닝할 수 있게 해줘." |
| 용어를 모를 때 | "[다크소울처럼 적을 고정하고 그 주위를 도는 것]을 언리얼에서 뭐라고 불러? 그걸로 구현해줘." |

마지막 줄이 핵심입니다. 용어를 몰라도 참고 게임과 원하는 느낌을 설명하고 "이걸 뭐라고 불러?"라고 물으면, AI가 용어를 알려주고 바로 구현까지 이어갑니다.
