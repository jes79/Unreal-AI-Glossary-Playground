# 새 레벨 추가하기

용어 하나 = 예제 레벨 하나 = 데모 액터 클래스 하나입니다. 레벨은 손으로 만들지 않고 빌더가 생성합니다.
자세한 규칙은 저장소의 `docs/CONVENTIONS.md` 를 보세요.

## 1. 카탈로그에 용어 추가

`Source/GlossaryCore/Private/GlossaryCatalogData.inl` 에 한 줄:

```cpp
GLOSSARY_ENTRY("0117", "LedgeGrab", "Ledge Grab", "벽 끝을 잡고 매달림", "벽 끝에 닿으면 매달리고 Space 로 올라가게 해줘.")
```

id 앞 두 자리가 분야, 이름은 클래스·레벨 이름에 그대로 쓰입니다.

## 2. 데모 클래스 작성

`Source/GlossaryMovement/Public/Demo0117_LedgeGrab.h` + `Private/Demo0117_LedgeGrab.cpp`, 클래스 이름은 반드시 `ADemo{id}_{Name}`.

```cpp
ADemo0117_LedgeGrab::ADemo0117_LedgeGrab()
{
	DemoId = TEXT("0117");
	Controls = TEXT("WASD 이동 · Space 점프\nC : Ledge Grab ON/OFF\n관찰: 벽 끝에서 매달린다");
	Showcase = TEXT("벽 끝 감지 → 매달리기 → 올라가기, ON/OFF 비교");
}
```

- 장면은 `BeginPlay` 에서 `GlossaryKit::SpawnShape / SpawnBlock / SpawnLabel` 로 만듭니다.
- 레벨에 저장돼야 하는 것(볼륨·정적 라이트)만 `BuildLevel(UWorld*)` 에서 놓습니다.
- 실시간 값은 `SetStatus()` 로 정보 패널에 표시합니다. 왼쪽 위 620×440 은 패널 자리입니다.

## 3. 빌드와 레벨 생성

```bash
tools/build.sh GlossaryMovement
tools/glossary-build.sh -filter=0117
```

## 4. 확인

```bash
tools/shot.sh 0117 8 C
```

레벨을 실행해 8초 뒤(그 전에 C 키를 누르고) `shots/0117.png` 로 저장합니다.

## 5. 문서

`docs/dev-notes/NN-*.md` 의 "id 별 표"에 한 줄 추가 → `tools/make-wiki.sh` 로 분야 위키 페이지 재생성.
