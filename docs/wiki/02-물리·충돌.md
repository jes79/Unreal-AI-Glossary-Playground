## 항목별 상세

### 0201

**Collision Preset / Object Channel** — 무엇과 막히고 무엇을 통과할지 정하는 표

> 요청 예문: "Projectile 오브젝트 채널을 만들고, 투사체는 Pawn과 Overlap, WorldStatic과 Block 되게 Collision Preset을 짜줘."

- 레벨: `/Game/Levels/02_Physics/L_0201_CollisionPreset`
- 데모 클래스: `ADemo0201_CollisionPreset` (`Source/GlossaryPhysics/Public/Demo0201_CollisionPreset.h`)
- 구현 방식: 런타임 데모
- 레벨에서 보여 주는 것: Projectile 오브젝트 채널 총알이 Pawn=Overlap·WorldDynamic=Block·Projectile=Ignore 로 다르게 반응, BlockAll 프리셋(1키)과 비교
