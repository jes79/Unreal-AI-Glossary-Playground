## 항목별 상세

### 0901

**Sound Cue (Random·Modulator)** — 여러 소리를 조합·변주하는 그래프

> 요청 예문: "발소리 4개를 Sound Cue의 Random 노드로 고르고 Modulator로 피치 0.9~1.1을 넣어 반복감을 없애줘."

- 레벨: `/Game/Levels/09_Audio/L_0901_SoundCue`
- 데모 클래스: `ADemo0901_SoundCue` (`Source/GlossaryAudio/Public/Demo0901_SoundCue.h`)
- 구현 방식: 런타임 데모 (진짜 Sound Cue 에셋)
- 레벨에서 보여 주는 것: 발소리 4개를 Random 으로 고르고 Modulator 피치 0.9~1.1, 고른 웨이브(색)·측정 피치(높이) 막대 그래프, C 로 웨이브 1개 고정과 비교

### 0902

**MetaSounds** — 노드로 소리를 만들고 제어하는 UE5 오디오

> 요청 예문: "MetaSound Source로 엔진 소리를 만들고 RPM 파라미터(0~1)를 코드에서 SetFloatParameter로 바꿔 피치가 오르게 해줘."

- 레벨: `/Game/Levels/09_Audio/L_0902_MetaSounds`
- 데모 클래스: `ADemo0902_MetaSounds` (`Source/GlossaryAudio/Public/Demo0902_MetaSounds.h`)
- 구현 방식: 런타임 데모 (MetaSound 빌더 API 로 만든 에셋)
- 레벨에서 보여 주는 것: MetaSound Source(RPM 입력→Map Range 40~220Hz→Saw)를 SetFloatParameter("RPM") 로 제어, 타코미터 바늘·피스톤

### 0903

**Attenuation (3D 거리 감쇠)** — 멀수록 작게, 방향에 따라 좌우

> 요청 예문: "모닥불 소리에 Sound Attenuation(Inner 200, Falloff 1500, Spatialization)을 넣어줘."

- 레벨: `/Game/Levels/09_Audio/L_0903_Attenuation`
- 데모 클래스: `ADemo0903_Attenuation` (`Source/GlossaryAudio/Public/Demo0903_Attenuation.h`)
- 구현 방식: 런타임 데모
- 레벨에서 보여 주는 것: 모닥불 소리 ATT_Campfire(Inner 200·Falloff 1500·Spatialization), 감쇠 링 2개·거리·계산 볼륨·Envelope·좌우 방향, C 로 ON/OFF

### 0904

**Sound Class / Sound Mix** — 배경음·효과음 볼륨 그룹

> 요청 예문: "Music·SFX·Voice Sound Class를 만들고, 옵션 슬라이더가 SetSoundMixClassOverride로 각 볼륨을 바꾸게 해줘."

- 레벨: `/Game/Levels/09_Audio/L_0904_SoundClassMix`
- 데모 클래스: `ADemo0904_SoundClassMix` (`Source/GlossaryAudio/Public/Demo0904_SoundClassMix.h`)
- 구현 방식: 런타임 데모
- 레벨에서 보여 주는 것: Music·SFX·Voice Sound Class + SMix_Options, 옵션 슬라이더(UMG) → SetSoundMixClassOverride, 그룹별 스피커·Envelope

### 0905

**Submix / Submix Effect** — 출력 단계에서 한꺼번에 효과 적용

> 요청 예문: "일시정지하면 SFX Submix에 Low Pass 필터를 걸어 소리가 먹먹하게 들리게 해줘."

- 레벨: `/Game/Levels/09_Audio/L_0905_Submix`
- 데모 클래스: `ADemo0905_Submix` (`Source/GlossaryAudio/Public/Demo0905_Submix.h`)
- 구현 방식: 런타임 데모
- 레벨에서 보여 주는 것: SFX Submix 에 Low Pass Submix Effect(Synthesis 플러그인 필터 프리셋), P 로 실제 일시정지하면 Cutoff 20000→500Hz, 서브믹스 스펙트럼 막대

### 0906

**Audio Volume (공간 리버브)** — 구역마다 울림이 다름

> 요청 예문: "동굴 안에 Audio Volume을 두고 Reverb Effect를 넣어 들어가면 소리가 울리게 해줘."

- 레벨: `/Game/Levels/09_Audio/L_0906_AudioVolume`
- 데모 클래스: `ADemo0906_AudioVolume` (`Source/GlossaryAudio/Public/Demo0906_AudioVolume.h`)
- 구현 방식: 런타임 데모 (+ 빌더가 레벨에 Audio Volume 저장)
- 레벨에서 보여 주는 것: 동굴 Audio Volume + RVB_Cave(Decay 4초), 손뼉 자동 재생, 안에서는 메아리 링 4겹, 볼륨 경계선, GetAudioSettings 로 현재 볼륨 표시

### 0907

**Sound Concurrency** — 같은 소리 동시 재생 제한

> 요청 예문: "총소리는 Sound Concurrency로 동시 4개까지만, 넘치면 가장 오래된 것을 끄게(Stop Oldest) 해줘."

- 레벨: `/Game/Levels/09_Audio/L_0907_Concurrency`
- 데모 클래스: `ADemo0907_Concurrency` (`Source/GlossaryAudio/Public/Demo0907_Concurrency.h`)
- 구현 방식: 런타임 데모
- 레벨에서 보여 주는 것: 총소리 0.1초 연사, SCon_Gunshot(Max 4, Stop Oldest) ON/OFF — 보이스 슬롯 16칸·한도선·끊긴 수

### 0908

**Quartz (박자 동기화)** — 음악 박자에 맞춰 소리·이벤트 실행

> 요청 예문: "Quartz Clock(BPM 120)을 만들고 항상 다음 박에 맞춰 타악기가 재생되게(PlayQuantized) 해줘."

- 레벨: `/Game/Levels/09_Audio/L_0908_Quartz`
- 데모 클래스: `ADemo0908_Quartz` (`Source/GlossaryAudio/Public/Demo0908_Quartz.h`)
- 구현 방식: 런타임 데모
- 레벨에서 보여 주는 것: Quartz Clock BPM 120, 박과 어긋난 시각에 요청해도 PlayQuantized 로 다음 박에 타악기 — 박 패드·재생 헤드·누름/재생 마커·대기 ms

### 0909

**Audio Component Fade** — 배경음을 부드럽게 바꾸기

- 레벨: `/Game/Levels/09_Audio/L_0909_AudioFade`
- 데모 클래스: `ADemo0909_AudioFade` (`Source/GlossaryAudio/Public/Demo0909_AudioFade.h`)

- 레벨에서 보여 주는 것: 전투 시작 시 잔잔한 BGM FadeOut 2초 + 전투 BGM FadeIn 2초, 스피커 크기·막대(계산 볼륨)·Envelope, 2 로 즉시 교체 비교
