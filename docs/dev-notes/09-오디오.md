# 09 오디오 (GlossaryAudio) 작업 노트

모듈 `Source/GlossaryAudio`, 레벨 `/Game/Levels/09_Audio/L_09xx_*`, 생성 에셋 `/Game/Glossary/09_Audio`.
소리는 스크린샷에 안 나오므로 모든 데모가 오른쪽 위 계기판(UGlossaryAudioPanel)과 3D 표시물로 "지금 무슨 일이 일어나는지"를 보여 준다.
공용 헬퍼: `GlossaryAudioKit.h` — UGlossaryAudioProbe(OnAudioSingleEnvelopeValue·OnAudioPlaybackPercent 수신, 재생 속도로 피치 추정),
UGlossaryAudioPanel(막대 계기판), UGlossaryAudioBanner(큰 글씨 배너), SpawnRing(바닥 링), CreateEngineRPMBuilder(MetaSound 그래프).

## 2. 생성 에셋 (/Game/Glossary/09_Audio, 빌더 `09_Audio` = GlossaryAudioAssets.cpp)

- 합성 사운드: S_Footstep_01~04, S_Campfire_Loop, S_Gunshot, S_Percussion, S_Clap, S_BGM_Calm_Loop, S_BGM_Battle_Loop, S_Chime_Loop, S_Voice_Loop, S_EngineHum_Loop(0902 대체용)
- SCue_Footsteps — Sound Cue: Wave Player×4 → Random(반복 없이) → Modulator(피치 0.9~1.1, 볼륨 0.9~1.0) → 출력. ConstructSoundNode + ChildNodes + LinkGraphNodesFromSoundNodes 로 그래프까지 생성
- MS_EngineRPM — MetaSound Source: UMetaSoundBuilderSubsystem::CreateSourceBuilder → 입력 RPM(Float) → MapRange(Float) → Saw → Mono Out, UMetaSoundEditorSubsystem::BuildToAsset
- ATT_Campfire — Sound Attenuation (Sphere, Inner 200, Falloff 1500, Linear, Spatialize)
- SC_Master / SC_Music / SC_SFX / SC_Voice — Sound Class 계층, SMix_Options — Sound Mix (세 클래스 Adjuster)
- SSub_SFX — Sound Submix (효과 체인: SSFX_LowPass = USubmixEffectFilterPreset, LowPass StateVariable, 기본 20000Hz)
- SCon_Gunshot — Sound Concurrency (MaxCount 4, StopOldest)
- RVB_Cave — Reverb Effect (Decay 4.0, Density/Diffusion 1, LateGain 1.8 …)
- 웨이브 라우팅: SFX 계열 → SC_SFX + SSub_SFX, BGM → SC_Music(Master), 목소리 → SC_Voice

## 3. 남은 문제 · 공통 변경 요청

- Build.cs 에 `Synthesis`(Low Pass 서브믹스 프리셋) 의존을 추가했다. Synthesis 플러그인은 엔진 기본 켜짐이라 .uproject 수정 없이 동작하지만, 명시하려면 .uproject Plugins 에 `Synthesis` 추가를 권장(요청).
- 에디터 전용 의존(UnrealEd, BSPUtils, AudioEditor, MetasoundEditor, EditorScriptingUtilities, AssetTools)은 `Target.bBuildEditor` 일 때만 추가.
- 엔진 기본 `UnfocusedVolumeMultiplier=0` 때문에 창이 비활성이면 소리가 0 이 되어 Envelope 계기판이 0 으로 보였다. 오디오 데모 BeginPlay 에서 `FApp::SetUnfocusedVolumeMultiplier(1)` 을 호출한다(GlossaryAudioKit::PrepareAudioDemo). 프로젝트 전체에 적용하려면 DefaultEngine.ini `[Audio] UnfocusedVolumeMultiplier=1.0` (요청, 선택).
- 커맨드렛에서 MetaSound 저장 시 `PreSaveAsset ... doing nothing` 경고 1개(오디오 렌더 불가 환경이라 생기는 무해한 경고).
- Envelope 는 엔진이 "거리 감쇠 전" 버퍼로 계산한다. 그래서 0903 의 거리 감쇠는 Evaluate() 계산값으로 보여 주고 Envelope 는 참고값.
- 0901 피치는 OnAudioPlaybackPercent 의 재생 속도(최소제곱 기울기 × 길이)로 추정한 근사값(±2% 정도).

## 4. 대체 구현 항목

- 없음. 모든 항목이 진짜 엔진 기능/에셋(Sound Cue, MetaSound, Attenuation, Sound Class/Mix, Submix Effect, Audio Volume+Reverb, Concurrency, Quartz, Fade)을 쓴다.
- 0902 만 안전장치가 있다: MS_EngineRPM 에셋이 없으면 실행 중 같은 MetaSound 빌더로 임시 MetaSound 를 만들고, 그것도 실패하면 S_EngineHum_Loop + SetPitchMultiplier 로 대체하며 상태 줄에 출처를 표시한다(현재는 에셋 경로로 동작).
- 0909 의 볼륨 막대는 엔진이 페이드 진행값을 읽는 API 를 제공하지 않아 FadeIn/FadeOut 과 같은 선형 곡선을 따라 계산한 값(측정값은 Envelope 줄).
