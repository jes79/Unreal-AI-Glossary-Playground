## 메모

- 모든 데모 액터는 `PrimaryActorTick.TickGroup = TG_PostPhysics` — 플레이어 컨트롤러 입력 처리 뒤에 Tick 해야 `WasKeyPressed` 를 놓치지 않는다(shot.sh 의 연속 키 주입에서 두 번째 키부터 누락되던 문제).
- 0807: `State` 는 ini 에 직접 없는 암시적 부모 태그라 `RequestGameplayTag("State")` 가 ensure 를 낸다 → `State.Stunned` 의 `RequestDirectParent()` 로 얻는다.
- 게임플레이 태그: `DefaultGame.ini` 의 `[/Script/GameplayTags.GameplayTagsSettings]` 목록이 실제로는 로드되지 않는다(이 설정은 DefaultGameplayTags.ini 에서 읽힘). 08 모듈은 `D08_Tags.h/.cpp` 에서 `UE_DEFINE_GAMEPLAY_TAG` 네이티브 태그로 State.*·Ability.Fireball·Ability.Cooldown.Fireball 을 직접 등록해 해결.
- shot.sh 로 키를 여러 개 넣으면 첫 키만 반영되는 경우가 많아, 키가 필요한 검증은 shot 한 번에 키 하나로 했다(0819 는 `0819_night.png` 에 T 한 번 누른 밤 장면).
- 0811 테두리: 후처리 외곽선 머티리얼 대신 Custom Depth(Stencil 1)를 켜고 노란 발광으로 강조.
- 0802: OpenLevel 로 같은 레벨을 다시 열면 shot.sh 키 순서가 처음부터 반복되므로 재로드는 로그(`[0802] 레벨 로드 #n`)로 확인.
