# 03 애니메이션 (GlossaryAnimation) — 작업 노트

모듈 `Source/GlossaryAnimation`, 레벨 `/Game/Levels/03_Animation/L_03xx_*`, 생성 에셋 `/Game/Glossary/03_Animation/`.

## 공통 구조

- `UD03_AnimInstance` (D03_AnimInstance.h/.cpp) — **C++ 로 쓴 AnimBP**.
  - Event Graph = `NativeUpdateAnimation` (Speed·Direction·IsFalling, Aim·LookAt·FootIK 입력 계산)
  - Anim Graph = 커스텀 `FAnimInstanceProxy::Evaluate` (워커 스레드): Blend Space 샘플링(공통 위상 동기) → Fall Loop 블렌드 →
    Slot(`SlotEvaluatePose`, 슬롯 등록·가중치 갱신까지 FAnimNode_Slot 과 같은 방식) → Layered Blend per Bone(LayerBone 이하만 슬롯 포즈)
    → 다리 비율(리타깃 비교) → 컴포넌트 공간 후처리(Aim Offset 척추 분배, Look At 목·머리 + Clamp, Foot IK = 골반 내리기 + `AnimationCore::SolveTwoBoneIK` + 발 경사 정렬)
  - 데모마다 플래그만 켜서 재사용. 몽타주·Notify·Root Motion 은 엔진 그대로 동작.
- `AD03_Mannequin` — 컨트롤러 없이 움직이는 NPC Manny(ABP_Unarmed 기본, `bRunPhysicsWithNoController`), 순찰·고정 방향·머리 라벨.
- `UD0305_AnimNotify_Hit` — 몽타주 타격 프레임용 C++ AnimNotify (전역 `OnHit` 델리게이트).
- `UD03_GraphWidget` — 오른쪽 아래 그래프 패널(NativePaint): Blend Space 격자, 몽타주 타임라인, 커브, 상태 다이어그램.

## 대체 구현 항목과 이유

- 0308 Aim Offset: AO 에셋은 조준 포즈(CU/CC/CD × L/C/R)가 필요한데 Unarmed 세트에 없음 → 같은 원리를 C++ AnimInstance 컴포넌트 공간 회전으로.
- 0310 Control Rig Look At: Control Rig 그래프(Aim 노드)는 에디터 전용 → 목 40%·머리 60% Aim + 60° Clamp + 보간을 C++ 로.
- 0311 IK Retargeter: IK Rig/Retargeter 에셋 작성은 에디터 전용이고 다른 스켈레톤 메시가 없음 → 다리 뼈 길이 배율로 '다른 체형'을 만들고 Retarget Root(골반 높이 비율 보정)를 재현.
- 0312 Motion Matching: PoseSearch Schema·Database·Motion Matching 노드는 AnimBP·에디터 인덱싱 필요 → 프레임 단위 특징 DB + 비용 최소 검색 + 블렌드 전환을 직접 구현.
- (참고) 0301·0307 은 AnimBP 그래프 대신 C++ AnimInstance(커스텀 프록시 Evaluate)를 쓰지만 엔진의 실제 API(Blend Space·SlotEvaluatePose·몽타주·Notify)를 그대로 써서 런타임 데모로 표시.
