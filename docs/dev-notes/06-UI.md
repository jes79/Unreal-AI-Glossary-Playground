# 06 UI·UX (UMG) — 작업 노트

모듈 `GlossaryUI` · 레벨 `/Game/Levels/06_UI/L_06xx_*` · 생성 에셋 없음(모두 실행 중 생성)

Widget Blueprint 는 코드로 만들 수 없으므로 모든 위젯은 `UGlossaryWidgetBase`(또는 `UUserWidget`/`UCommonActivatableWidget`) 를 상속해
`WidgetTree->ConstructWidget` 으로 트리를 만든다. 공용 헬퍼는 `GlossaryUIKit.h`(MakeText/MakeBorder/MakeButton/MakeBar/WrapSize/SetupFixedCamera).
폰이 필요 없는 UI 데모는 `PlayerPawnClass = nullptr` + `GlossaryUIKit::SetupFixedCamera` 로 고정 카메라를 쓴다.

## 남은 문제 · 공통 변경 요청
- **tools/shot.sh 키 여러 개가 첫 키만 눌리는 버그** (GlossaryCore `AGlossaryPlayerController::BeginPlay`):
  `FParse::Value(..., TEXT("GlossaryShotKeys="), KeyList)` 가 기본값 `bShouldStopOnSeparator=true` 라서 쉼표에서 끊긴다.
  → `FParse::Value(FCommandLine::Get(), TEXT("GlossaryShotKeys="), KeyList, false)` 로 바꾸거나 shot.sh 가 값을 따옴표로 감싸도록 요청.
  (지금은 `tools/shot.sh 0601 12 '"One,Two"'` 처럼 값에 따옴표를 넣으면 동작한다. 3프레임 유지 변경 후에도 파싱은 그대로)
- 0616: 프로젝트 설정 Common Input Settings 에 Input Data(Default Back Action 데이터 테이블)가 없어 Common UI 의 Back 액션 바인딩 대신
  위젯 `NativeOnKeyDown` 에서 Esc/패드 B → `HandleBackAction` 으로 보낸다. DefaultGame.ini 에 `[/Script/CommonInput.CommonInputSettings] InputData=...` 를
  설정하면 코드 수정 없이 진짜 Back 바인딩으로 바뀐다(`bIsBackHandler` 자동 전환).
- 0613: OpenLevel 은 동기 로딩이라 실제 로딩 중엔 위젯이 멈춘다. 진행률 바는 OpenLevel 직전까지의 연출(정보 표시함).
- 0602: DPI 커브는 실행 중 `UUserInterfaceSettings` CDO 를 바꿔 비교한다(에디터 빌드는 배율 캐시가 없어 즉시 반영, EndPlay 에서 복원).
- 0609: 에디터 빌드의 `UListViewBase::RebuildWidget`(final)은 EntryWidgetClass 가 Blueprint 클래스가 아니면 오류 문구만 그린다. WBP 를 못 만드는 이 예제는 `UDemo0609_ItemListView` 생성자에서 C++ 엔트리 클래스의 `bCooked=true` 로 검사를 건너뛴다(EntryWidgetClass 는 protected UPROPERTY 라 서브클래스 생성자에서 지정). 실제 프로젝트는 엔트리를 WBP 로 만들면 불필요.
- 0608: 일시정지 중엔 게임 시간이 멈춰 공용 자동 캡처(AGlossaryPlayerController::TickAutoShot)가 진행되지 않는다. 데모 쪽에서 `-GlossaryShot` 일 때만 실제 시간으로 직접 캡처·종료하는 보조 코드를 넣었다. 공용 쪽을 `FApp::GetDeltaTime()` 기준으로 바꾸면 이 보조 코드는 지워도 된다(요청).
- 0616: Common UI 기본 `NativeOnHandleBackAction` 은 `bIsBackHandler` 일 때만 DeactivateWidget 하므로, Back 데이터가 없을 때는 직접 `DeactivateWidget()` 한다. 한 프레임에 여러 번 push 하면 스택이 꼬여(아래 화면이 빠짐) G 시연은 프레임마다 한 단계씩 push.

## 대체 구현 항목과 이유
- 0601 WBP 는 코드로 못 만든다 → 같은 위젯 트리를 C++ 서브클래스에서 조립. 권장 패턴(WBP 의 Parent Class = `UDemo0601_HudBase`, `UPROPERTY(meta=(BindWidget))`)을 베이스 클래스로 그대로 보여 준다.
- 0607 WBP Animations 탭은 에디터 전용 → `UWidgetAnimation` + `UMovieScene` + `UMovieScene2DTransformTrack`(RenderTransform)·`UMovieSceneFloatTrack`(RenderOpacity) 키를 실행 중 조립해 `PlayAnimationForward/Reverse` 로 재생 (진짜 위젯 애니메이션 재생 경로).
- 0616 `UCommonButtonBase` 는 스타일 에셋이 필요 → 일반 UButton. Back 액션은 위 요청 참고.
- 0617 MVVM View Bindings(WBP Viewmodels 패널)는 에디터 전용 → View 는 `AddFieldValueChangedDelegate` 로 같은 FieldNotify 알림을 직접 구독. 뷰모델은 실제 `UMVVMViewModelBase`.
- 0618 Localization Dashboard(.locres)는 Gather/Compile 이 필요 → 같은 네임스페이스·키의 한국어 번역을 `FPolyglotTextData` 로 실행 중 등록. String Table(`LOCTABLE_NEW`)·`FText::FromStringTable`·`SetCurrentCulture` 는 실제 기능.
