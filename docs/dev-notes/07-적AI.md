## 생성 에셋 (`/Game/Glossary/07_AI`, 빌더 `07_AI`)
- `M_AgentColor` — 단색 머티리얼(Usage: Skeletal Mesh·Instanced Static Mesh). 공통 M_Color 는 스켈레탈 메시 Usage 가 없어 Manny 에 쓰면 회색이 됨.
- `BB_Enemy`, `BT_Enemy` — 실행 노드(RootNode 트리)는 저장되지만 BT 에디터 그래프(BTGraph)는 비어 있다. 런타임은 정상. 에디터에서 BT_Enemy 를 열어 저장하면 트리가 지워지므로 열기만 할 것.
- `ST_Enemy` — UStateTreeEditorData(상태·태스크·전환·조건)를 코드로 채우고 UStateTreeEditingSubsystem::CompileStateTree 로 컴파일. StateTree 편집기에서 그대로 보인다.
- `SOD_Bench` — USmartObjectDefinition(슬롯 3개 + UD0711_SitBehaviorDefinition).

## 메모
- 레벨 저장 액터(BuildLevel): 0707 Nav Modifier Volume 2개(브러시), 0708 Nav Link Proxy(Smart Link). 0708 은 실행 중 스폰한 고지대가 NavMesh 에 반영되도록 2.5초 뒤 출발 (shot 에서 "링크 점프 1회" 확인).
- 실행 중 스폰하는 벽·고지대는 Dynamic NavMesh(RuntimeGeneration=Dynamic)가 다시 굽는다.
- StateTree 노드는 인스턴스 데이터 타입이 없으면 "Malformed node" 로 컴파일 실패 → 모든 태스크·조건에 FD0710_TimerData 지정.
- 엔진 BT 노드의 protected 프로퍼티(BlackboardKey, FlowAbortMode, OperationType 등)는 D07::SetProperty/SetBlackboardKey 리플렉션으로 설정.
- 0708 OnSmartLinkReached 는 C++ 에서 protected 라 FMulticastDelegateProperty::AddDelegate 로 바인딩.
- Build.cs: MassCore·WorldConditions 추가, 에디터 전용 UnrealEd·StateTreeEditorModule·BSPUtils·PropertyBindingUtils.
